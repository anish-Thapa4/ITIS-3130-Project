# DineDecide Prototype

## Launch

This is a static website and requires no build step. To host it with GitHub Pages:

The HTML, CSS, and JavaScript files need to stay together in the repository root.

## About this project

DineDecide is an interactive prototype created for an ITIS 3130 project. It demonstrates a possible restaurant discovery and decision-making experience; it is not a production app or a live restaurant service. Restaurant names and details are fictional demonstration data.
